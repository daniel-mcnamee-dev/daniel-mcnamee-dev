# Featured Projects

## ChessPrep

![Status](https://img.shields.io/badge/status-completed-brightgreen)

Desktop chess preparation and analysis application built with C#, WPF, and MVVM architecture.

The project includes:

* interactive chessboard and move replay
* opening explorer with ECO dataset integration
* Chess.com game browser
* local two-player gameplay
* legal move validation and highlighting
* board orientation controls
* move annotations and game saving

Repository
[https://github.com/daniel-mcnamee-dev/ChessPrep](https://github.com/daniel-mcnamee-dev/ChessPrep)

## ChessInsight

![Status](https://img.shields.io/badge/status-completed-brightgreen)

Full-stack chess analysis and replay platform built with Angular, Node.js, Express, and MongoDB.

The application integrates with the Chess.com API to allow users to:

* search players
* browse historical games
* replay matches move-by-move
* create persistent move annotations
* manage favourite and recent games

Live Demo
